# Project Description

It is a personal website that displays skills and projects developed. 

It features several skills and languages, projects linked to github repos, about me, contacts, and much more!

## Prerequisites

Node.js (v16+) and npm installed. Check versions:
  node -v
  npm -v

## HOW TO RUN

1. Open up the project in the correct directory :\my-portfolio
2. Run: npm run build
3. Run: npm run dev
4. Open up link: http://localhost:5173/
5. Enjoy my website :)
